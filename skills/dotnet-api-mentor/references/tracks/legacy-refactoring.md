# Legacy code and refactoring track (Level 4 to 5)

How to read an unfamiliar codebase fast, characterization tests before changing legacy code, safe refactoring in small steps, strangler pattern for migration, upgrading from .NET Framework or older .NET versions, TFVC to Git migration, dealing with huge classes and stored procedures, and deciding when to rewrite (rarely) vs refactor. Exercise: give a messy legacy class, have the user add tests first, then refactor in steps with the tests green.
