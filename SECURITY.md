# Security and training data

.NET Forge is a mentoring skill, not a production healthcare application. Its hospital domain is for synthetic exercises only.

Do not include credentials, real patient data, real trainee personal information, or unredacted production logs in issues, pull requests, progress examples, or reports. The `learning/` directory is ignored and belongs to each trainee's private workspace.

If a problem could expose sensitive information, do not post that information in a public issue. Use GitHub's private vulnerability reporting if it is available for this repository, or contact the maintainer through an existing private channel. Do not assume a private reporting feature is enabled.

Reports should describe the affected file or protocol, the failure scenario, the impact, and a minimal synthetic reproduction. Do not attach live tokens or real patient records as proof.

Only the current main branch is reviewed for fixes at this stage. No response-time SLA, production-safety guarantee, or security certification is implied.
